# 🌍 Civilization Simulator

> **A C++-based civilization simulator** featuring multiple races, territorial expansion, warfare and diplomacy, technological development, cultural diffusion, random events, and many other rich mechanics. Running on a 600×600 world map, it simulates thousands of years of civilizational rise and fall.

## ✨ Features

- **World Map**: 600×600 grid with 24 layers of geographic data (elevation, temperature, precipitation, biome, soil fertility, mineral resources, etc.), generated by external tools (compatible with binary `.bin` format).
- **Multi-Civilization Management**: Supports five races—Human, Dwarf, Elf, Orc, and Halfling—each with unique bonuses in growth, combat, technology, and diplomacy.
- **Dynamic Kingdoms**: The first kingdom is established at initialization; new kingdoms may automatically splinter off over time (up to 30 total).
- **Territorial Expansion**: Expand territory through military or economic means; each tile has a "control degree" mechanic.
- **Economy & Resources**: Gold, food, military units, stability, tax rates, and other core resources; realistic economic simulation including gathering, taxation, maintenance costs, corruption, and royal extravagance.
- **Technology Tree**: 30+ technologies across agriculture, military, industry, navigation, magic, culture, and economy—researchable, spreadable, and transferable between kingdoms.
- **Warfare System**: Declarations of war, peace treaties, allied intervention, world wars; combat simulation based on terrain, commanders, and army strength, with casualties, resource depletion, and war exhaustion effects.
- **Diplomacy & Alliances**: Alliance probability determined by cultural similarity, common enemies, and diplomatic personality; alliances can fracture, and allies can coordinate in battle.
- **Civilization Level**: Dynamic rise and fall based on overall cultural health, technology, stability, population, and territory, affecting all attribute modifiers.
- **Internal Politics**: Stability affected by food, warfare, and tax rates; can trigger rebellions, revolutions, and royal succession events.
- **Road System**: A* pathfinding to build imperial roads connecting settlements and capitals, reducing maintenance costs and improving defense.
- **Random Events**: Domestic overt events (noble infighting, trade booms, etc.), covert events, natural disasters (volcanoes, earthquakes, floods), and magical catastrophes (if magic toggle is enabled).
- **Cultural Diffusion**: Cultural values spread between neighboring territories, influencing diplomacy and assimilation.
- **Settlement Management**: Automatically or manually construct new settlements; build 50+ types of buildings (farms, barracks, markets, temples, etc.), each providing different bonuses.
- **Output System**: After simulation, generates detailed kingdom archives, historical events, road networks, territorial distributions, summaries of fallen nations, and more as text files.

## 🛠️ Tech Stack

- **Language**: C++14 (using the standard library, no external dependencies)
- **Compilation Environment**: GCC / Clang / MSVC (C++14 support required)
- **Map Data Format**: Binary `.bin` (recommended) or text `WORLDMAP` (legacy compatibility)
- **Random Engine**: `std::mt19937` (fixed seed for reproducibility)

## 🚀 Quick Start

### Prerequisites

- A C++14-compatible compiler (e.g., g++ 5.0+, clang 3.4+, Visual Studio 2015+).
- World map file (default `worldmap.bin`); you can generate it using the companion tool (e.g., `Weather-Terrain`).

### Compilation & Execution

```bash
# Clone or download the source code
git clone https://github.com/yourusername/civilization-simulator.git
cd civilization-simulator

# Compile (using g++ as an example)
g++ -std=c++14 -O2 -o civilization Civilization7.1.cpp

# Run (ensure worldmap.bin is in the current directory)
./civilization
```

The simulation will run for **2000 turns** (each turn representing 3 months) and generate result files in the `output/` directory.

## 📦 Installation & Configuration

This program is a single-file project and requires no additional libraries. Simply:

1. **Prepare the map file**: Place `worldmap.bin` (or legacy `worldmap.txt`) in the same directory as the executable.
2. **Adjust parameters (optional)**: Modify the `constexpr` constants at the beginning of the code to change world dimensions, number of turns, initial resources, probabilities, etc.
3. **Compile**: Follow the compilation command above.

> **Note**: The map file must match the `WORLD_WIDTH`, `WORLD_HEIGHT`, and `BUFFER_SIZE` values in the program (default 600×600, buffer 0). If using binary format, the file header must be `"WORLDMAPBIN"`.

## 📊 Usage

After execution, the simulator automatically performs the following steps:

1. Loads the map and initializes the first kingdom (race adaptively chosen based on the birth environment).
2. Each turn executes in order:
   - Resource gathering, population growth, building construction, territorial expansion, new settlement establishment.
   - Technology research, stability updates, rebellion/revolution checks, royal lifespan.
   - Road construction and maintenance, cultural diffusion, control degree recovery.
   - Diplomacy/alliance updates, war handling, allied intervention, world war detection.
   - Various events (domestic, covert, natural disasters, magical catastrophes).
   - Dynamic generation of new kingdoms.
3. Every 20 turns, outputs snapshots to the console.
4. After the simulation ends, writes all outputs to the `output/` directory.

### Console Output Example
```
[0] New kingdom "Golden Capital Kingdom" established at (312, 287), race: Human
[5] Human Kingdom discovered new technology: "Irrigation"
[12] Human Kingdom declared war on Dwarf Kingdom!
...
===== Turn 200 (Year 50) | Surviving Kingdoms: 8/12 =====
```

## 📁 Output Files

After the simulation ends, the `output/` directory will contain:

- `kingdom_<id>.txt`: Detailed information for each surviving kingdom (resources, population, cities, buildings, technologies, royal history, etc.).
- `fallen_kingdoms.txt`: Summary of all fallen kingdoms, including fall turn and peak territory/population.
- `international.txt`: Records of international events and world stability assessment.
- `roads.txt`: Road network statistics (road tile count and maintenance cost per kingdom).
- `territory.txt`: Territorial coordinates and settlement lists for each kingdom.
- `history.txt`: Complete historical event log (chronologically sorted).

These files can be used for subsequent analysis or visualization.
