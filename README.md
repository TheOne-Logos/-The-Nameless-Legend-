I am an independent developer and currently still a high school student. This project is a challenge beyond my comfort zone, and a long‑term practice for me in system design, procedural generation, and narrative design.

## Game Features
- A whole continent, countries, and history are procedurally generated each time you start a new game.
- Procedurally generated factions, quests, and NPCs.
- Imperfect intelligence – maps, rumors, and quest descriptions may contain errors.
- Terminal aesthetics: ASCII art, frame‑by‑frame animations, and pure text‑based storytelling.
- A silent world – there are no right answers.
